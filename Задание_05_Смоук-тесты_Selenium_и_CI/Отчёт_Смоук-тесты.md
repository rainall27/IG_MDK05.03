## 1. Что такое смоук-тест
Смоук-тест - быстрая проверка, что основные сценарии приложения вообще работают. Он не ищет мелкие дефекты: если смоук-тест упал, дальше тестировать сборку нет смысла. Здесь выбраны пять сценариев, без которых портал не нужен.

## 2. Инструменты
| Что | Версия |
|---|---|
| Язык | Python 3 |
| Автоматизация браузера | Selenium WebDriver 4 |
| Запуск тестов и отчёт | pytest, pytest-html |
| Браузер | Chrome (в проверке: Chromium 141, headless) |
| Объект тестирования | портал «Конференции.РФ» (Flask), репозиторий `IG_MDK09.01`, папка `ПР11_Веб-приложение_по_ТЗ/code` |
| CI | GitHub Actions |

## 5. Запуск в CI
Файл [`.github/workflows/selenium.yml`](../.github/workflows/selenium.yml) запускает тесты на GitHub при каждом `push` и `pull request`, а также вручную (кнопка «Run workflow»):

| Шаг | Что делает |
|---|---|
| Checkout тестов | скачивает этот репозиторий |
| Checkout приложения | скачивает репозиторий `IG_MDK09.01` в папку `app` |
| Python | ставит Python 3.12 |
| Зависимости | ставит Flask (для приложения) и Selenium, pytest, pytest-html |
| Задание 4 и Задание 5 | запускают тесты, каждый шаг создаёт `report.html` |
| Артефакты | сохраняет отчёты и снимки упавших тестов (`artifacts/`) для скачивания |

На GitHub-раннере Ubuntu уже установлены Chrome и chromedriver, поэтому дополнительная настройка браузера не нужна. Отчёт после запуска скачивается на странице запуска во вкладке Actions, раздел Artifacts. Если репозиторий приложения закрытый, нужно добавить секрет `APP_REPO_TOKEN` с токеном доступа к нему. Для открытого репозитория секрет не нужен.

Важно: в CI тест запускается впервые только после публикации репозиториев на GitHub. В этой работе workflow проверен на корректность синтаксиса, а сами тесты запущены локально (раздел 7).

## 6. Как запустить локально
```
cd C:\IG\IG_MDK05.03\Задание_05_Смоук-тесты_Selenium_и_CI\code
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install -r C:\IG\IG_MDK09.01\ПР11_Веб-приложение_по_ТЗ\code\requirements.txt
set APP_DIR=C:\IG\IG_MDK09.01\ПР11_Веб-приложение_по_ТЗ\code
python -m pytest -v -m smoke --html=report.html --self-contained-html
```
Что делает каждая строка:

- `cd` - переход в папку с тестами;
- `python -m venv venv` и `venv\Scripts\activate` - создают и включают отдельное окружение Python;
- первый `pip install` ставит Selenium, pytest и pytest-html, второй - Flask, на котором работает приложение;
- `set APP_DIR=...` - указывает, где лежит приложение «Конференции.РФ» (если репозитории `IG_MDK05.03` и `IG_MDK09.01` лежат рядом, эту строку можно пропустить);
- `python -m pytest ...` - запускает тесты и сохраняет отчёт `report.html`.

Нужен установленный Google Chrome. Драйвер Selenium подбирает сам. Приложение тест запускает и останавливает самостоятельно, на временной базе данных.

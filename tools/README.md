# Повторный сбор материалов

Нужны Python 3.12+, Chrome, Firefox и зависимости из приложения ПР11 и Selenium-тестов. Репозитории располагаются рядом.

```text
python tools/collect_evidence.py --app-dir ../IG_MDK09.01/ПР11_Веб-приложение_по_ТЗ/code --output evidence
```

Скрипт создаёт временную SQLite-базу, добавляет демонстрационные данные, запускает сервер, сохраняет реальные SQL-выборки, четыре HTTP-запроса через CDP, снимки и проверки двух браузеров. После завершения сервер останавливается. PNG SQL-выборок — снимки текстовых файлов, открытых в браузере. Повторные хеши и номера портов могут отличаться.

`check_failure_capture.py` запускает один заведомо ошибочный сценарий на временной копии тестов. Код возврата 1 и снимок падения обязательны; рабочие тесты не меняются.

Оба сценария запускаются в [workflow Evidence](../.github/workflows/evidence.yml). Обычный [workflow Selenium](../.github/workflows/selenium.yml) проверяет 16 тестов входа и 5 smoke-тестов; вывод, HTML и PNG сохраняются в артефактах.
